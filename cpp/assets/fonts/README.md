# Fontes do cliente

- `Fraunces-SemiBold.ttf`: a fonte de títulos da demo (`demo/vendor/fonts/fraunces-latin-600-normal.woff2`),
  convertida de WOFF2 para TTF sem outra mudança. Licença OFL: `Fraunces-OFL.txt`.
- `DejaVuSans.ttf`, `DejaVuSans-Bold.ttf`: fonte do corpo de texto (a demo usa a fonte sans do sistema).
  Licença Bitstream Vera / domínio público: `DejaVu-LICENSE.txt`.
